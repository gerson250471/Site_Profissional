# MAJB Sistemas - Portfólio Profissional

Este é o repositório oficial do portfólio da MAJB Sistemas. O projeto foi desenvolvido para apresentar soluções de automação de processos, desenvolvimento de sistemas sob medida e consultoria técnica para empresas.

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando uma arquitetura moderna e escalável:

Backend: Node.js com framework Express.

Frontend: HTML5, Tailwind CSS (estilização) e Lucide Icons.

Deploy: Automatizado via GitHub Actions (CI/CD) para servidores Hostinger via FTP.

Especialidades Destacadas:

Microsoft Access & Excel (VBA).

Google Apps Script (Automação Workspace).

Integrações de Bancos de Dados.

## 🛠️ Como Executar Localmente

Se desejar testar o projeto em sua máquina local:

Clone o repositório:

```
git clone [https://github.com/seu-usuario/seu-repositorio.git](https://github.com/seu-usuario/seu-repositorio.git)
```

Instale as dependências:

```
npm install
```

Inicie o servidor:

```
npm start
```

O site estará disponível em http://localhost:3000.

## 🌐 Deploy Automático (CI/CD)

Este projeto está configurado para atualizar automaticamente na Hostinger sempre que um push é realizado na branch main.

Para que o deploy funcione, é necessário configurar os seguintes Secrets no repositório do GitHub:

FTP_SERVER: Endereço do host FTP.

FTP_USERNAME: Usuário da conta FTP.

FTP_PASSWORD: Senha da conta FTP.
